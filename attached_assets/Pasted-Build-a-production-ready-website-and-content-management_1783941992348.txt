Build a production-ready website and content-management platform for a Māori organisation called Legacy Pathways.
Project purpose
Legacy Pathways exists to preserve, present and develop the stories and legacy of Māori servicemen, particularly those connected with Ōhinemutu, Te Arawa and Muruika Urupā.
The website must operate as:
1. A public history and education platform.
2. A searchable roll call and soldier-story archive.
3. A future QR-code destination for graves at Muruika Urupā.
4. An ecommerce storefront.
5. A media and podcast platform.
6. A tour-information and enquiry website.
7. A public home for the Takrouna carving project.
This should feel like a serious, modern heritage organisation, not a tourism-template website or a generic “Māori-themed” website.

Design direction
Create a design that is:
* Respectful, contemporary and authoritative.
* Story-led and image-led.
* Easy for kaumātua, whānau, students and general visitors to navigate.
* Strong on mobile because QR-code visitors will usually arrive by phone.
* Inspired by remembrance, whakapapa, military history, whenua and intergenerational legacy.
* Restrained rather than decorative.
Avoid generic koru borders, random Māori patterns, token cultural decoration or invented symbolism.
Until Legacy Pathways supplies final branding, use a temporary visual system based on:
* Charcoal and near-black. And white and red
* Strong editorial typography.
* Generous whitespace.
* Large archival photographs .
Support macrons and te reo Māori correctly throughout the website. Do not automatically invent Māori translations. Include editable bilingual fields so approved translations can be added later.

Historical data import
The organisation intends to use information associated with the public roll at:
28maoribattalion.org.nz/roll
Do not immediately scrape, duplicate or republish its text, images, oral histories or complete database.
First build a safe import architecture that can be activated only after the organisation confirms written permission and the permitted scope of reuse.
Initial import method
For the first version:
* Build an administrator CSV import tool.
* Provide a downloadable CSV template.
* Allow approved public facts to be entered manually.
* Allow source links to point visitors back to the original profile.
* Include duplicate detection using name, service number and source URL.
* Display an import preview before saving.
* Require an administrator to approve imported records.
* Log all imports and changes.
Future authorised importer
Prepare, but do not automatically run, an import script capable of:
* Following pagination.
* Reading basic roll fields.
* Reading authorised profile fields.
* Rate limiting requests.
* Respecting robots.txt, copyright restrictions and terms of use.
* Saving source URLs and import timestamps.
* Updating records without overwriting manually verified information.
* Producing an error and conflict report.
* Stopping safely if the source layout changes.
Do not run the importer without an environment variable such as:
AUTHORISED_ROLL_IMPORT=true
Set this to false by default.
Selecting Te Arawa and Ōhinemutu people
Do not assume that automated text matching can reliably establish whakapapa, iwi affiliation or burial location.
Create an administrator workflow where the system can suggest possible connections based on:
* Recorded addresses.
* Next-of-kin addresses.
* Place names.
* Existing profile text.
* Known iwi or company information.
* Approved lists supplied by Legacy Pathways.
Every suggested association must be manually confirmed before public publication.
QR-code system
Build a QR-management section inside the admin dashboard.
For each approved profile, allow administrators to:
* Generate a permanent QR code.
* Download it as SVG and high-resolution PNG.
* Download a print-ready PDF label.
* Include the person’s name and service number.
* Link it to the permanent public profile URL.
* Disable a QR destination without deleting the profile.
* Redirect an old URL if a slug changes.
* Record when and where a QR code was installed.
* Add an internal grave or memorial reference.
* View privacy-conscious scan counts.
Do not include third-party advertising, trackers or unnecessary cookies on QR landing pages.
Make profile pages load quickly on weak mobile connections.
